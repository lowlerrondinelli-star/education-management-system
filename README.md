# 教务管理系统

面向教培机构日常运营的教务管理系统，目标覆盖从意向学员登记、报名缴费、分班排课、上课记录、课时消耗到续费跟进的核心业务闭环。

## 当前阶段

本仓库目前处于需求分析与本地原型阶段。初版分析参考了本地模板目录：

`C:\Users\6\Downloads\导入模板`

## 本地运行

Windows 下可以直接双击：

`启动本地原型.bat`

也可以手动运行：

```bash
cd app
python -m http.server 5177
```

然后在浏览器打开：

`http://localhost:5177`

## 本地原型已包含

- 运营总览：学员数、待上课、开课班级、欠费提醒。
- 学员管理：学员列表、全局搜索、快速新增学员、学员详情档案。
- 订单课时：报名订单、购买课时、赠送课时、已上课时、余额、欠费补缴、收款流水。
- 基础资料：课程、教师、教室维护，并用于排课表单选择。
- 员工权限：员工档案、岗位角色、模块权限预览，支持校长、前台、教务、教师、财务等角色。
- 班级管理：班级容量、教师、助教、教室、扣课规则。
- 排课管理：本周班级课与 1 对 1 课表，自动检查教师、教室、班级/学员时间冲突。
- 点名考勤：课前点名，到课/迟到消课，请假/旷课不消课。
- 消课管理：课时流水与操作记录。
- 续费跟进：自动生成欠费、课时不足、意向回访待办，支持记录跟进结果和下次跟进时间。
- 经营报表：按课程、教师、班级、渠道汇总收入、欠费、课消、满班率和排课工作量。
- 数据中心：本地 JSON 备份恢复，学员、订单 CSV 批量导入校验，以及学员、订单、班级、课程、教师、教室、员工、角色、考勤、收款、课表、排课冲突、续费跟进、学员详情汇总、经营报表、消课流水 CSV 导出。
- 模板字段库：展示 Excel 模板字段、必填字段、导入规则和真实模板工作表预览。

当前原型数据存储在浏览器 `localStorage`，适合先本地试用和讨论流程；后续可以替换为数据库和登录权限。

## Excel 模板预览

启动脚本会先运行：

```powershell
scripts\extract-template-data.ps1
```

该脚本会读取：

`C:\Users\6\Downloads\导入模板`

并生成：

`app\excel-data.json`

前端“模板字段库”页面会自动读取这份 JSON，展示每个 `.xls` 文件、工作表、字段、必填项和示例行。

## 批量导入

当前本地原型支持在“数据中心”导入学员档案和订单课时。老师可以先在 Excel 中整理表格，再另存为 UTF-8 CSV 文件导入；系统会检查必填、手机号、数字、日期、班级关联和重复手机号，并返回中文错误报告。

## MVP 目标

第一阶段优先完成以下能力：

1. 学员/意向学员档案管理
2. 课程、报价单、班级基础资料管理
3. 报名订单与课时账户管理
4. 班级课表与 1 对 1 课表管理
5. 上课记录与自动消课
6. 基础员工、角色、权限管理
7. Excel 导入导出与数据校验

## 建议技术方向

后续可以按 Web 管理系统实现，支持多校区、多角色登录。技术栈待确认后再定，建议优先选择成熟、易维护、适合中小团队交付的方案。
