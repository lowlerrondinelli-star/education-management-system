# 教务管理系统

面向教培机构日常运营的教务管理系统，目标覆盖从意向学员登记、报名缴费、分班排课、上课记录、课时消耗到续费跟进的核心业务闭环。

## MVP 目标

第一阶段优先完成以下能力：

1. 学员/意向学员档案管理
2. 课程、报价单、班级基础资料管理
3. 报名订单与课时账户管理
4. 班级课表与 1 对 1 课表管理
5. 上课记录与自动消课
6. 基础员工、角色、权限管理
7. Excel 导入导出与数据校验

## 建议技术方向

后续可以按 Web 管理系统实现，支持多校区、多角色登录。技术栈待确认后再定，建议优先选择成熟、易维护、适合中小团队交付的方案。
