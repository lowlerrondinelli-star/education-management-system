# 教务管理系统

面向教培机构日常运营的教务管理系统，目标覆盖从意向学员登记、报名缴费、分班排课、上课记录、课时消耗到续费跟进的核心业务闭环。

## 当前阶段

本仓库目前处于需求分析与本地原型阶段。初版分析参考了本地模板目录：

`C:\Users\6\Downloads\导入模板`

## 本地运行

Windows 下可以直接双击：

`启动本地原型.bat`

也可以手动运行：

```bash
cd app
python -m http.server 5177
```

然后在浏览器打开：

`http://localhost:5177`

## 本地原型已包含

- 运营总览：今日工作台、校区交接日报、快捷入口、待上课表、欠费与课时不足提醒，并适配手机/窄屏使用。
- 老师工作台：按当前登录老师聚合待上课节、待点名、待反馈和关联学员，老师可从一屏进入点名、课后反馈和课时流水。
- 招生线索：咨询登记、跟进状态、试听安排、转为学员，支持招生线索 CSV 导出。
- 学员管理：学员列表、状态/班级/待处理筛选、欠费和课时不足风险视图、跨模块全局搜索、快速新增学员、学员详情档案；输入姓名、手机号、班级、课程或老师，可同时查看相关学员、订单、班级、课节、跟进和反馈。
- 订单课时：报名订单、购买课时、赠送课时、已上课时、余额、订单风险清单、收款日报、欠费/课时不足/有效期筛选、欠费补缴、退费、订单作废、课时调整、收款流水。
- 基础资料：课程、教师、教室维护，并用于排课表单选择。
- 员工权限：员工档案、岗位角色、登录员工切换、模块权限控制与操作审计，支持校长、前台、教务、教师、财务等角色。
- 班级管理：班级容量、教师、助教、教室、扣课规则、班级详情与花名册。
- 智能分班：按课程、年级、订单班级、容量和课时状态生成分班建议，支持一键分入推荐班级并导出核对表。
- 排课管理：本周班级课与 1 对 1 课表、课表清单、课前签到单、老师/教室/状态/日期筛选，支持单节排课、周期排课、调课、取消课程、安排补课，并自动检查教师、教室、班级/学员时间冲突。
- 点名考勤：课前准备清单、课前点名，到课/迟到消课，请假/旷课不消课。
- 请假补课：登记家长请假、审批处理、考勤异常核对、自动联动考勤为请假，并为学员安排补课课节。
- 消课管理：课时流水与操作记录。
- 课后反馈：老师可按课节给每位学员记录课堂表现、作业、家长话术和续读风险，支持家长通知核对、保存草稿、标记已发送与 CSV 导出。
- 续费跟进：自动生成欠费、课时不足、意向回访待办，支持记录跟进结果和下次跟进时间。
- 经营报表：按课程、教师、班级、渠道汇总收入、欠费、课消、满班率和排课工作量。
- 数据中心：本地数据文件绑定与自动保存、本地 JSON 备份恢复，学员、订单、课程、教室、员工、班级、班级日程、1 对 1 日程 CSV 批量导入校验；支持系统内全量数据表预览、异常筛选、数据体检，以及招生线索、学员、订单、班级、班级花名册、课程、教师、教室、员工、角色、操作日志、考勤、课前准备、课后反馈、家长通知核对、请假补课、收款、财务异常、课表、排课冲突、周期排课、调课补课记录、续费跟进、学员详情汇总、经营报表、校区交接日报、消课流水、考勤异常核对 CSV 导出。
- 模板字段库：展示 Excel 模板字段、必填字段、导入规则和真实模板工作表预览。

当前原型会先把数据存储在浏览器 `localStorage`；在支持 File System Access API 的浏览器中，也可以到“数据中心”绑定一个本地 JSON 数据文件，系统保存业务数据时会自动同步写入该文件。后续可以替换为 SQLite/服务端数据库和正式账号登录。

## Excel 模板预览

启动脚本会先运行：

```powershell
scripts\extract-template-data.ps1
```

该脚本会读取：

`C:\Users\6\Downloads\导入模板`

并生成：

`app\excel-data.json`

前端“模板字段库”页面会自动读取这份 JSON，展示每个 `.xls` 文件、工作表、字段、必填项和示例行。

## 批量导入

当前本地原型支持在“数据中心”导入学员档案、订单课时、课程报价、教室资料、员工资料、班级资料、班级日程和 1 对 1 日程。老师可以先在 Excel 中整理表格，再另存为 UTF-8 CSV 文件导入；系统会检查必填、手机号、数字、日期时间、角色、课程、教师、教室、班级关联和重复数据，并返回中文错误报告。

## MVP 目标

第一阶段优先完成以下能力：

1. 学员/意向学员档案管理
2. 课程、报价单、班级基础资料管理
3. 报名订单与课时账户管理
4. 班级课表与 1 对 1 课表管理
5. 上课记录与自动消课
6. 基础员工、角色、权限管理
7. Excel 导入导出与数据校验

## 建议技术方向

后续可以按 Web 管理系统实现，支持多校区、多角色登录。技术栈待确认后再定，建议优先选择成熟、易维护、适合中小团队交付的方案。
