# 教务管理系统

面向教培机构日常运营的教务管理系统，目标覆盖从意向学员登记、报名缴费、分班排课、上课记录、课时消耗到续费跟进的核心业务闭环。

## 当前阶段

本仓库目前处于需求分析与本地原型阶段。初版分析参考了本地模板目录：

`C:\Users\6\Downloads\导入模板`

## 本地运行

Windows 下可以直接双击：

`启动本地原型.bat`

也可以手动运行：

```bash
cd app
python -m http.server 5177
```

然后在浏览器打开：

`http://localhost:5177`

## 本地原型已包含

- 运营总览：今日工作台、角色快捷入口、校区交接日报、快捷入口、待上课表、欠费与课时不足提醒，并适配手机/窄屏使用；首页欠费提醒可直接打开对应订单补缴，课时不足提醒和统一待办续费项可直接带入学员打开新增跟进；校区交接日报里的跟进、续费和请假事项也可直接处理具体学员或请假单，减少换班后再搜索。
- 清爽界面：运营总览、经营报表、订单、班级、课表、学员、老师工作台、请假补课、课后反馈、基础资料、招生线索、续费跟进、数据中心、导入模板和员工权限等高频页面默认优先展示数据表、课表和看板，新增报名、新增班级、快速分班、新增排课、周期排课、新增课程/教师/教室、新增线索、跟进和员工角色等办理表单收纳为右侧“功能按钮/常用操作”栏，需要时再展开并自动定位到表单，保存后自动收起回到数据视图；首页默认保留今日工作台、关键指标、最近课表和待办提醒，统一待办、运营流程、交接日报和角色入口收纳为右侧按钮；经营报表默认保留经营概览和校区健康度，经营洞察、课程经营、教师班级、招生渠道和教师课时核对收纳为右侧按钮；课表页默认只看本周课表，排课健康、课前签到、资源占用和课表清单收纳为右侧“查看面板”按钮；学员页默认只看学员列表，报名办理台和学员运营看板收纳为右侧“查看面板”按钮；班级页默认只看班级容量表，班级运营看板和智能分班建议收纳为右侧“查看面板”按钮；订单页默认只看订单与课时账户表，续费欠费、收款日报、订单风险、财务异常、收款对账和课时核对收纳为右侧“查看面板”按钮；老师工作台默认保留今日待上、我的学生、待写反馈和最近已上，课前准备、班级花名册、上课闭环和任务清单收纳为右侧“查看面板”按钮；请假页默认保留请假补课闭环和最近待处理，请假登记、请假明细和考勤异常核对通过右侧按钮打开；反馈页默认保留课后反馈工作台，课节状态、反馈记录和家长通知核对收纳为右侧“查看面板”按钮；招生线索页默认保留线索工作台，线索明细收纳为右侧“查看面板”按钮；续费跟进页默认保留跟进工作台，跟进记录收纳为右侧“查看面板”按钮；数据中心默认保留本地数据概览和全量数据表，CSV 导入、导入准备、数据体检、体检明细和字段审计收纳为右侧按钮；导入模板页默认保留模板核对清单，字段总览、字段卡片和本地模板清单收纳为右侧按钮，减少页面平铺内容。
- 老师工作台：按当前登录老师聚合待上课节、待点名、待反馈、课节闭环和关联学员，老师可从一屏完成点名、确认上课、课后反馈、查看流水与闭环核对。
- 招生线索：咨询登记、跟进状态、试听安排、转为学员，支持招生线索 CSV 导出；新增线索可先选择转介绍、到店、线上、测评、比价等咨询样例，一键带出姓名、手机号、手机号归属、年级、学校、渠道、负责人、课程、意向度、跟进日期和备注，也可切换转介绍试听、到店高意向、线上咨询、测评邀约、比价观望等咨询场景模板继续微调；年级、学校、负责人、意向课程、线索备注和试听备注使用下拉选择，跟进日期、试听日期和试听时间段也提供常用模板；安排试听时可选择明晚标准试听、周六上午测评试听、周末下午家长旁听、线上晚间试听、校长测评试听等方案，一键带出试听日期、时间段、科目、老师、教室和回访备注，试听科目、试听老师和教室优先从基础资料中选择，切换试听科目后自动推荐匹配老师和教室，减少前台重复录入。
- 学员管理：学员列表、状态/班级/待处理筛选、欠费和课时不足风险视图、跨模块全局搜索、快速新增学员、学员详情档案；报名办理台可按阶段直接定位线索记录、带入学员报名、打开学员订单、分班或按班级筛选上课课表；列表和学员运营看板可直接为某个学员打开新增跟进并带入推荐场景；全局搜索命中订单、班级、课节、线索、跟进、请假记录时可直接补缴、打开学员订单、班级详情、班级排课、班级订单、定位课表、线索记录、学员跟进或处理请假单；列表直接显示最近待办跟进摘要，新增学员时可选择来访样例和建档场景，一键带出姓名、手机号、家长关系、年级、学校、渠道、销售员、意向课程、当前阶段和目标班级，选择班级后自动带出课程与报名状态；输入姓名、手机号、班级、课程或老师，可同时查看相关学员、订单、班级、课节、跟进和反馈。
- 订单课时：报名订单、购买课时、赠送课时、已上课时、余额、订单风险清单、收款日报、欠费/课时不足/有效期筛选、风险处理建议、欠费补缴、退费、订单作废、课时调整、收款流水；快速报名选择学员后会按意向课程、目标班级、容量和欠费情况自动推荐报读班级、课程、套餐和推荐理由，课程、报名套餐、付款状态、收款方式、收款账户和收款备注优先下拉选择，选择套餐后自动填充购买课时、赠送课时和有效期，选择按套餐默认、全款收齐、订金锁班、分两期、优惠收齐等付款状态模板后自动带出实收金额、欠费金额和收款备注，选择收款方式后自动带出对应账户，保存后把收款备注同步写入流水；欠费补缴可选择全额微信、全额转账、分期补缴、订金锁班、线下已收复核、现金补缴等收款场景模板，自动带出本次金额、方式、账户和备注；财务异常处理可选择部分退费、全额退费、转班退差额、赠课补录、扣课修正、订单作废等处理模板，自动带出金额、课时、方式和原因，减少手工录入。
- 基础资料：课程、教师、教室维护，并用于排课表单选择；新增课程可选择初中同步小班、组合课、高中提高班、一对一、小学英语小班、考前冲刺等报价模板，自动带出课程名、科目、年级、课型、授课方式、标准课时和标准价；新增教师可选择初中数学、高中物理、小学英语、助教、班主任等岗位模板，新增教室可选择标准小班、高中理科、一对一、线上直播、自习托管等教室模板，自动带出科目/年级/角色/容量/校区/用途备注，统一后续报名、分班和排课口径。
- 员工权限：员工档案、岗位角色、登录员工切换、模块权限控制与操作审计，支持校长、前台、教务、教师、财务等角色；权限策略覆盖报名、分班、排课点名、请假补课、课后反馈和续费跟进等一键办理按钮，角色预览也展示招生线索、请假补课、续费跟进、经营报表等模块，避免员工能看到入口却不能顺手办理；新增员工时可选择教务/学管、前台招生、任课教师、兼职教师、财务收银、校长管理员等入职岗位模板，自动带出姓名样例、员工类型、部门、角色、是否教师、科目和年级，新增角色时可按分校教务主管、招生前台主管、兼职教师、财务复核员、分校校长等角色模板自动带出角色名称、说明、模块权限和允许动作，减少后台维护口径不一致。
- 班级管理：班级容量、教师、助教、教室、扣课规则、班级详情与花名册；新增班级时可选择班级模板，自动生成班名、容量、扣课和教师课时，课程、教师、助教、教室、班型阶段和状态优先下拉选择，建班后可直接用于报名、分班和排课；班级运营看板和班级详情里的排课按钮会直接打开新增排课并带入该班级，班级运营看板也可直接带班级打开快速分班、筛选班级订单，并对欠费订单一键补缴。
- 智能分班：按课程、年级、订单班级、容量和课时状态生成分班建议，快速分班选择学员后会自动带出推荐班级和推荐理由；可选择日常总览、新报名优先、风险复核、课程匹配、容量宽松、订单班级复核等分班场景模板，自动联动筛选和排序，支持一键分入推荐班级并导出核对表。
- 排课管理：本周班级课与 1 对 1 课表、课表清单、课前签到单、老师/教室/状态/日期筛选和课节下一步提示，支持单节排课、周期排课、调课、取消课程、安排补课；报名办理台的待排课班级可一键打开新增排课并带入班级资源；单节排课可选择日期模板，选择班级/对象后会按该班历史课表或班型习惯自动带出科目、老师、教室、推荐时间段和推荐理由，周期排课也复用同一套班级推荐默认项，并可选择秋季每周晚一、每周两次晚课、周末上午强化、周末连排、暑假集训、1 对 1 晚间等方案，一键带出日期范围、星期、时间段和课节类型，支持周六周日排课；单节、周期排课、调课和补课可直接选择常用上课时间段并自动填入开始/结束时间，调课/补课还可选择明天原时间、最近周六、下周一晚一、线上同时间、下周同时间补课等处理方案模板，自动带出日期、时间、教室和原因，老师、教室、科目、操作人与原因优先下拉选择，并自动检查教师、教室、班级/学员时间冲突。
- 点名考勤：课前准备清单、课前点名、批量点名，到课/迟到消课，请假/旷课不消课；课前签到单、上课执行闭环和课节闭环会把欠费/低课时学员的跟进按钮直接带入具体学员，减少课后再搜索；点名时可选择常规上课、一人迟到、一人请假、一人旷课、欠费/零课时学员先请假等场景模板，快速生成整节课点名结果；确认上课后提供课节闭环指引，老师可继续核对点名、写课后反馈、查看消课流水和处理续费风险。
- 请假补课：登记家长请假、审批处理、考勤异常核对、自动联动考勤为请假，并为学员安排补课课节；课表卡片、课表清单、课前准备清单和考勤异常核对里的“请假/补请假”按钮会直接打开请假补课页右侧登记表单并带入原课节，快速登记选择课节后会自动把学员下拉限定为本节课名单；快速登记和课表内课节请假都可选择病假需补课、事假需补课、学校活动冲突、迟到转请假、天气/交通无需补课、长期停课待确认等场景模板，安排补课时可选择下周同时间、最近周六下午、晚间一对一、线上同时间、老师空档等补课安排模板，一键带出补课日期、时间段、老师和教室；申请人、处理人、请假原因、补课建议、补课时间段、补课老师和教室都可直接选择，减少前台手工录入。
- 消课管理：课时流水、操作记录和待消课辅助面板；默认展示流水筛选和余额风险，待消课课节收纳到右侧按钮，待办卡片会直接显示建议处理方案、预计消课人数、合计扣课、未扣课人数和资金风险，未点名课节可按建议点名，已点名课节点击确认消课时会先打开扣课预览，自动列出每位学员扣课前后余额、欠费和课时不足风险，并可选择按点名消课、欠费/零课时先不扣、全部到课、整节请假等消课场景模板；未点名课节先补点名。
- 课后反馈：老师可按课节给每位学员记录课堂表现、作业、家长话术和续读风险，课堂表现、作业和家长话术优先使用模板选择；课表、老师工作台、统一待办、交接日报和上课闭环中的反馈按钮会先进入课后反馈工作台并带入课节，再打开反馈表单；反馈表单可选择按考勤常规反馈、整体进步表扬、基础巩固提醒、高风险需回访、缺勤补看课堂等场景模板，一次套用表现、风险、作业和家长话术，支持批量套用话术、家长通知核对、保存草稿、标记已发送与 CSV 导出；家长通知核对里的高风险、欠费和低课时学员可直接带入新增跟进；高风险反馈会自动同步为续费跟进待办。
- 续费跟进：自动生成欠费、课时不足、意向回访待办，支持记录跟进结果和下次跟进时间；新增跟进选择学员后会按欠费、低课时和意向状态自动推荐跟进场景，并带出跟进类型、跟进人、日期、结果、优先级和备注；也可手动选择欠费当天催缴、课时不足续费、约定缴费复核、意向试听邀约、未接通再联系、高风险反馈安抚等跟进场景模板和常用备注模板。
- 经营报表：按课程、教师、班级、渠道汇总收入、欠费、课消、满班率和排课工作量。
- 数据中心：本地数据文件绑定与自动保存、本地 JSON 备份恢复，学员、订单、课程、教室、员工、班级、班级日程、1 对 1 日程 CSV 批量导入校验；选择导入类型后会直接显示导入顺序、依赖资料、校验重点、准备清单，并可下载样例、查看对应本地 Excel 模板或切到当前数据表；支持系统内全量数据表预览、当前表字段完整度摘要、缺失字段提示、异常筛选、数据体检，以及招生线索、学员、订单、班级、班级花名册、课程、教师、教室、员工、角色、操作日志、考勤、课前准备、课后反馈、家长通知核对、请假补课、收款、财务异常、课表、排课冲突、周期排课、调课补课记录、续费跟进、学员详情汇总、经营报表、校区交接日报、消课流水、考勤异常核对 CSV 导出。
- 模板字段库：展示 Excel 模板字段、必填字段、导入规则和真实模板工作表预览。

当前原型会先把数据存储在浏览器 `localStorage`；在支持 File System Access API 的浏览器中，也可以到“数据中心”绑定一个本地 JSON 数据文件，系统保存业务数据时会自动同步写入该文件。后续可以替换为 SQLite/服务端数据库和正式账号登录。

## Excel 模板预览

启动脚本会先运行：

```powershell
scripts\extract-template-data.ps1
```

该脚本会读取：

`C:\Users\6\Downloads\导入模板`

并生成：

`app\excel-data.json`

前端“模板字段库”页面会自动读取这份 JSON，展示每个 `.xls` 文件、工作表、字段、必填项和示例行。

## 批量导入

当前本地原型支持在“数据中心”导入学员档案、订单课时、课程报价、教室资料、员工资料、班级资料、班级日程和 1 对 1 日程。老师可以先在 Excel 中整理表格，再另存为 UTF-8 CSV 文件导入；系统会按所选导入类型提示先导入哪些基础资料、哪些字段必须核对，并能一键跳到对应模板清单和当前数据表；系统会检查必填、手机号、数字、日期时间、角色、课程、教师、教室、班级关联和重复数据，并返回中文错误报告。

第一阶段优先完成以下能力：

1. 学员/意向学员档案管理
2. 课程、报价单、班级基础资料管理
3. 报名订单与课时账户管理
4. 班级课表与 1 对 1 课表管理
5. 上课记录与自动消课
6. 基础员工、角色、权限管理
7. Excel 导入导出与数据校验

## 建议技术方向

后续可以按 Web 管理系统实现，支持多校区、多角色登录。技术栈待确认后再定，建议优先选择成熟、易维护、适合中小团队交付的方案。
