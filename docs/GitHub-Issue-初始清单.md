# GitHub Issue 初始清单

以下 issue 可用于第一阶段项目管理。

## 1. 梳理 MVP 业务流程

标签：需求、MVP、高优先级

内容：明确意向学员、报名、分班、排课、消课的主流程和异常流程。

验收标准：形成确认版 MVP 流程文档，每个流程包含角色、输入、输出和关键校验。

## 2. 确认 1 对 1 业务建模方式

标签：需求、数据库、待确认

内容：评估 1 对 1 是特殊班级还是独立对象，并确认对排课、消课、订单、报表的影响。

## 3. 确认多校区权限范围

标签：需求、权限、待确认

内容：确认是否支持总部/校区两级管理、员工跨校区任职、跨校排课冲突检测。

## 4. 设计核心数据表

标签：设计、数据库、高优先级

内容：设计学员、员工、课程、报价单、班级、订单、课时账户、课节、出勤、课时流水等表。

## 5. 设计 Excel 导入校验框架

标签：设计、导入导出、高优先级

内容：支持必填校验、格式校验、字典校验、关联对象校验和错误报告。

## 6. 实现员工与角色管理

标签：后端、前端、MVP

内容：员工新增、编辑、停用；员工类型、部门、角色、是否教师、可授科目/年级。

## 7. 实现学员档案与意向学员

标签：后端、前端、MVP

内容：学员基础信息、联系人、来源渠道、销售员、年级、学校、地址、手机号唯一性。

## 8. 实现课程与报价单

标签：后端、前端、MVP

内容：课程管理、报价单管理、售卖状态、授课方式、体验价、微校上架状态。

## 9. 实现班级与分班

标签：后端、前端、MVP

内容：班级创建、关联课程、满班人数、班主任、默认教师、默认教室、学员加入/退出。

## 10. 实现报名订单与课时账户

标签：后端、前端、MVP

内容：创建按课时订单，记录购买课时、赠送课时、实收、欠费、有效期，生成课时账户和购买流水。

## 11. 实现班级排课

标签：后端、前端、MVP

内容：创建班级日程，支持重复规则，生成课节，校验教师、助教、教室冲突。

## 12. 实现 1 对 1 排课

标签：后端、前端、MVP

内容：创建 1 对 1 日程，支持教师、助教、教室、科目、备注、重复排课。

## 13. 实现上课确认与消课

标签：后端、前端、MVP、高优先级

内容：教师或教务确认上课，记录学员出勤，自动扣减课时，写入课时流水。

## 14. 编写导入模板兼容性测试

标签：测试、导入导出

内容：每个 Excel 模板至少覆盖 1 个成功用例和 5 个失败用例。

## 15. 编写完整业务流程端到端测试

标签：测试、MVP

内容：新增学员、创建订单、分班、排课、确认上课、消课、查看余额。
