- 是否体验价
- 是否上架微校

- 满班人数
- 班主任

- 默认上课教室
- 开班日期
- 结班日期
- 课时记录方式：固定课时数、按上课时长记录课时
- 学生扣除课时数
- 教师记录课时数
- 期段
- 分数段
- 学段
- 年份
- 科目
- 班级状态

- 退出日期

- 所属校区
- 容量

### 字典 Dictionary

- 字典类型
- 字典值
- 排序
- 是否启用

## 2. 关系概览

- 一个学员可以有多个联系人、多个报名订单、多个课时账户。
- 一个课程可以有多个报价单，也可以被多个班级关联。
- 一个班级关联一个普通课程或组合课程，并包含多个学员。
- 一个班级可以生成多个课节。
- 一个 1 对 1 日程可以视为特殊课节，也可以在后续建独立 OneOnOneGroup。
- 一个课节可以有多个出勤记录。
- 每次有效消课都必须写入课时流水。

## 3. 需要优先设计的约束

- 学员主手机号建议全局唯一，若允许同手机号多个学员，需要增加家庭维度。
- 课程名称、班级名称、教师姓名、教室名称在导入时需要有明确匹配规则。
- 金额、课时数、日期、手机号需要独立校验器。
- 重复日程需要保存规则和生成结果，便于后续批量调课。
- 删除关键业务数据建议使用停用/作废，不做物理删除。
