# 项目管理方案

## 仓库定位

本仓库用于管理教培机构教务管理系统的需求、设计、开发、测试和本地原型。

## 建议里程碑

- M0：需求与原型，确认业务流程、数据模型和页面原型。
- M1：基础资料与权限，完成员工、角色、字典、教室。
- M2：学员与招生，完成意向学员、正式学员、跟进和导入。
- M3：课程、班级、订单，完成课程报价、分班、报名和课时账户。
- M4：排课与消课，完成班级课、1 对 1、重复排课、上课确认和课时流水。
- M5：报表、测试与发布，完成经营报表、导出、权限测试和部署文档。

## 分支规则

- `main`：稳定版本。
- `develop`：集成分支。
- `feature/模块名`：功能分支。
- `fix/问题名`：缺陷修复分支。

## 测试策略

- 单元测试：手机号、日期、金额、课时、重复规则。
- 接口测试：学员、订单、班级、课表、消课。
- 导入测试：逐个 Excel 模板准备成功和失败样例。
- 端到端测试：报名、分班、排课、上课、消课、查余额。
